# 3D Rotating Cube Navigation Menu

A modern, minimalist 3D cube navigation component built using **HTML** and **CSS**.

## Features

- 3D rotating cube using CSS transforms
- Smooth infinite rotation animation
- Glassmorphism-inspired design
- Responsive layout
- Pure HTML & CSS (No JavaScript)

## Folder Structure

```text
demo.html
style.css
README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Customize the navigation labels and colors as needed.
